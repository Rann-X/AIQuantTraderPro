# 六阶段开发与验收

目标为Windows公开行情、可解释策略、风险与独立模拟、AI解释/通知、真实历史回测和可视化终端。第一版不提供真实自动交易。

| 阶段 | 已实现内容 | 实际验证证据 |
|---|---|---|
| 1 项目与行情 | 模块化配置/日志，官方REST/双WS，四币种×三周期，盘口/标记价/资金费/24h变化，重连/限流/SQLite/健康API | live-probe.json、live-stage3.json；1000秒soak.json，包括主动断开和跨15m收盘恢复 |
| 2 指标与策略 | 全部请求指标、趋势/机会/触发、异常量/高波动/横盘/冲突，正式信号只读确认K线 | indicator-reference-final.json：240项独立标量检查；因果截断/未来数据不影响历史决策测试 |
| 3 风控与模拟 | Decimal仓位/成本/预算、最小张数/合约乘数/第一逐仓阶梯，深度成交、多空/平仓/止盈止损/资金费/强平/流水 | tests-stage3.xml、risk-real-data-smoke.json四币种真实盘口虚拟开平仓；UI完整开平仓测试 |
| 4 解释与通知 | 本地事实解释、指标冲突/历史表现/复盘，兼容API事实组织与安全回退，Windows提醒/去重/冷却 | 模型接口与事实约束测试、未部署回退、原生Toast API实际系统测试；用户确认模型尚未部署 |
| 5 回测与终端 | 真实价格/标记/资金费数据、固定参数样本内外、成本/胜率/回撤/连亏、七个Streamlit/Plotly页面、配置保存 | data/history/manifest.json、BACKTEST.md/backtest.json，tests-stage5.xml，浏览器实际图表与回退检查 |
| 6 部署与综合验收 | Windows安装/启动/停止及五进程管理、状态写入容错、性能优化、手册/风险/API/扩展文档、源码包和wheel | install-tests.xml/install-verification.txt、tests-final.xml、performance.json、integration.json、发行清单 |

每阶段均实际执行测试、修复发现的问题、静态检查和数据核验，并更新文档。早期分阶段测试报告保留作过程记录，最新结果以tests-final.xml和ACCEPTANCE.md为准。

V1明确边界：只开放第一保证金阶梯逐仓，历史回测没有逐笔盘口，当前规则代替不可获得的历史规则版本；均在风险/回测中说明。
兼容模型未部署是用户确认的环境现状，交付可配置适配器与经测试的本地回退，不声称已验证某个真实模型的线上推理。
稳定性证据覆盖约17分钟而非数周运行；更长验证和高阶梯/逐笔撮合为后续扩展，不作已实现声明。
