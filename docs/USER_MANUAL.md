# 操作使用手册

## 安装与运行

安装Python 3.11+并启用PATH，完整解压源码安装包，双击install.bat。脚本创建项目虚拟环境、安装依赖、检查冲突并运行测试。
Python3.14使用requirements-win-py314.lock约束；其他版本按兼容范围安装，本次未逐一验证。双击start.bat打开http://127.0.0.1:8501。
首次联网获取四币种数据约30秒。停止用stop.ps1，关闭网页不会停止后台进程。

可用start-market.ps1、start-api.ps1、start-paper.ps1、start-assistant.ps1单独运行模块，避免与完整启动器重复占用端口。

## 七个页面

| 页面 | 操作与实际结果 |
|---|---|
| 市场总览 | 每5秒刷新成交价、24h涨跌、趋势、候选状态、数据年龄和风险 |
| 行情与指标 | 切换币种/周期，缩放K线与指标图，开关图例、导出图；淡色未完成K线只展示，不生成信号 |
| AI分析 | 查看实时价、信号收盘参考价、触发/失效条件和风险；调用兼容模型；查看历史策略复盘 |
| 交易模拟 | 初始化虚拟账户、预算预览、模拟多/空、平仓、查看持仓/复盘及导出流水 |
| 策略回测 | 下载真实数据，设置天数/点差/成交参与限制/换算情景，运行样本内外测试，导出报告 |
| 风险管理 | 输入方向、张数、止盈止损与换算情景，计算保证金、仓位、成本、计划损失、强平估算及价格变化损益 |
| 系统设置 | 校验并保存币种、周期、策略、风控与通知参数；测试Windows通知 |

## 模拟账户与交易

进入交易模拟，默认本金100元人民币。填写自己选定的人民币每USDT换算率、来源及观察时间（UTC毫秒，默认当前时间，可修改）。
初始化余额=人民币本金/换算率，保存到独立data/paper.sqlite3，不读取OKX真实账户。使用假设汇率时请在来源说明中写明“假设情景”。
本软件未替你初始化正式使用的模拟账户。

选择合约与long/short方向，填写张数、止损和目标价，先预算预览。张数、价格必须满足合约最小数量、步长和tick。
点击提交模拟开仓时重新审核当时行情、预算和资金费，可能因市场变化拒绝。成交逐档消耗真实可见盘口并加不利滑点，不足深度全单拒绝。
每币种最多一个逐仓持仓，当前采用整笔开平仓。手动平仓或让后台模拟监控执行止盈止损和强平优先检查。

默认20倍，单笔含成本计划损失≤当前权益2%，日损失预算≤日初权益5%，日损失保守累计，不以盈利抵销。
最低张数也超过预算即放弃交易。V1限制官方第一保证金阶梯，尚不开放更高阶梯逐级减仓模型。
初始化时将风控参数写入账本，修改系统设置不会偷偷改变已有账户历史规则。模拟请求去重、账本与流水原子提交。

自动退出需要行情和paper watch均在运行。停机/断网期间不虚构成交，恢复后按实际观察行情处理。
资金费对账使用历史realizedRate与结算分钟标记开盘价采样，缺失时等待数据。计划止损不是实际损失保证上限。

## 信号与通知

正式规则只读取已完成K线：15m趋势、5m机会、1m动能与成交量共振，并通过波动与成本过滤。
无共振、K线不足/过期/有缺口或实时ticker超过10秒时显示暂不交易。当前成交价与信号收盘参考价分开。
候选不等于账户风险审核通过。Windows提醒包含币种、方向、当前价、触发条件、止损止盈、风险和北京时间。
默认同币种300秒冷却，全局10秒间隔；勿扰模式可能隐藏横幅，API成功只代表Windows接受请求。

## 兼容模型

模型不是运行前提。本地grounded_rules能解释真实行情、冲突、风险和已记录交易。
部署兼容Chat Completions API后，在启动前设置QUANT_LLM_BASE_URL、QUANT_LLM_MODEL，需要密钥时只设置QUANT_LLM_API_KEY环境变量。
模型仅选择与组织事实ID，不能修改价格或生成订单。未知事实、请求失败或未部署均回退本地解释。
点击AI页按钮或显式使用assistant_cli --llm才调用模型；默认后台不发送行情到外部模型。

## 回测

附带2026-11-05至2026-11-14（不含结束日）真实价格、标记K线和实际资金费。前两天预热，七天评估按时间70%/30%分样本内外。
每币种单独100元情景账户，不是四币种共享100元组合。固定参数，不自动寻优，零成交如实保留。
无历史盘口，点差/滑点与前一分钟成交量参与上限为明确执行假设。按下一根K线入场；同一分钟触发止盈止损时止损优先，强平优先。
实际回测存在亏损，不能把历史结果当作未来收益预测。完整假设、参数、费用和拒绝原因可在页面与报告查看。

## 文件与排错

| 路径 | 内容 |
|---|---|
| config.toml | 不含密钥的配置，修改后台设置后重启启动器 |
| data/market.sqlite3 | 行情、合约、阶梯与状态 |
| data/paper.sqlite3 | 独立虚拟账户与交易流水 |
| data/notifications.sqlite3 | 通知去重 |
| data/history/ | 含SHA256清单的真实历史数据 |
| reports/ | 回测、测试、性能和稳定性证据 |
| logs/ | 分进程日志与启动器日志 |

备份前先stop.ps1，再复制paper.sqlite3及仍存在的同名-wal/-shm文件。不要删除已有账本来解决行情问题。
行情未就绪：检查OKX可达性、代理、系统时间和日志。端口占用：先关闭独立启动的同类服务，软件不会结束其他应用。
配置会先验证再保存，错误输入显示原因。测试临时文件使用项目work目录，避免Windows默认TEMP权限问题。
