# 指标与规则定义

分析只使用confirm=1且开盘时间+周期≤决策时间的K线。各周期分别按决策时间截断。
缺口、重复、币种混合、周期混合、数据不足100根或过期，一律停止生成候选。

MA为收盘价简单均线；EMA使用adjust=False递推，9/21期预热；MACD为12/26 EMA差，9期信号线。
RSI14和ATR14使用首个14期SMA作为种子，随后Wilder平滑；RSI无涨跌时50、只有上涨时100。
布林为20期均值±2倍总体标准差。支撑/压力为前20根最低/最高，不含当前K线。
量比为当前成交张数/前20根平均张数。VWAP为UTC自然日内当前载入窗口的USDT成交额/基础币成交量，
若窗口未覆盖该日零点则是部分日VWAP；该指标当前仅供展示，不参与交易规则。
指标使用浮点；成交和仓位金额将在第三阶段独立使用Decimal。

15分钟：收盘价、EMA21、MA60按方向排列，EMA21斜率同向且EMA21与MA60相对价差≥0.05%。
5分钟：收盘突破前20根支撑/压力，或穿过EMA21后收回并出现同向实体。
1分钟：EMA9/EMA21、MACD柱同向，做多RSI为50–75，做空为25–50，量比≥1.2。
任一周期ATR/收盘价>2%禁止候选。无完整共振时显示“暂不交易”。这些是研究规则，不声称有盈利优势。

止损距离为5分钟ATR×1.5，目标为止损距离×2.5。双边成本率=2×(单边taker费率+单边滑点率)，
净收益风险比=(目标距离−双边成本)/(止损距离+双边成本)，不足1.5则拒绝。
费率/滑点是config.toml中的研究假设，不代表用户真实VIP费率或实时盘口执行成本；资金费另行计算。
候选在下一根1分钟K线完成时到期。风险预算、最小张数、盘口深度在独立风险/模拟模块审核；纯策略结果risk_approved恒为false。

API：GET /analysis/BTC-USDT-SWAP。current_price为真实ticker价，附current_price_ms；reference_close为独立的确认K线参考价，附price_close_ms。
实时价触及参考止损或目标会撤销旧候选；实时价格只能使信号失效，不用于创造新的规则方向。
返回触发条件、失效条件、方向、参考价格、止损止盈、毛/净收益风险比、成本率、异常量/波动/横盘/指标冲突与各周期指标。
